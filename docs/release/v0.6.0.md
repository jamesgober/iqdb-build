# iqdb-build v0.6.0 — Alpha: real-backend integration

**The builder meets the real indexes.** v0.5.0 froze the public API; v0.6.0 is the
alpha entry — it proves the generic builder constructs the *actual* iQDB indexes,
now that they exist. No new public surface: the API is exactly as committed at
0.5.0. The release is numbered `0.6.0` to sit on the iQDB family's version line
(`iqdb-flat` / `iqdb-hnsw` are at `0.6.0`).

## What is iqdb-build?

The bulk-construction layer of the iQDB vector database — generic over
`iqdb_index::Index`, so the same builder constructs and merges flat, HNSW, IVF, or
custom backends. It splits input into shards, builds them in parallel, and merges
them back into one index.

## What's new in 0.6.0

- **`tests/real_backends.rs`** — integration tests that drive the whole
  construction surface against the **real** backends:
  - `build::<FlatIndex>` and `build::<HnswIndex>` construct genuine indexes and
    return correct nearest-neighbour results.
  - `IndexBuilder::with_config` threads each backend's own `Config` (flat's unit
    config; a tuned `HnswConfig` with `ef_search`/`m` overrides) through unchanged.
  - `build_parallel` shards both backends across the pool; the shard counts and
    totals are exact.
  - `build_into` appends to both — including through a `&mut dyn IndexCore` trait
    object, the form the engine holds.
  This is the roadmap's §0.6 milestone: integrate against real consumers.
- **`tests/consumer_simulation.rs`** — an end-to-end soak test that drives the
  whole public surface the way `iqdb` would (build, configured build, parallel
  sharded build, `build_merged` with progress, incremental `build_into`, `merge`,
  search/delete), asserting parallel-merged recall matches a sequential build.

`iqdb-flat` and `iqdb-hnsw` are path **dev**-dependencies — dropped from the
published manifest — so the coupling is test-only; iqdb-build's runtime
dependencies are unchanged (`iqdb-index`, `iqdb-types`, `rayon`).

## Breaking changes

**None.** The public API is unchanged from the 0.5.0 freeze; this release adds
tests and a version bump only.

## Verification

```bash
cargo fmt --all -- --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test --all-features        # unit + property + loom-gated + real-backend + doctests
RUSTDOCFLAGS="-D warnings" cargo doc --no-deps --all-features
cargo deny check
```

Tested across the CI matrix (Linux, macOS, Windows) on stable and the 1.87 MSRV.

## What's next

- **0.7.x → 0.9.x — beta / RC.** Integrate against the `iqdb` engine, broader
  testing, final benchmarks, and doc polish.
- **1.0.0 — stable**, once the Definition of Done holds and the builder has proven
  itself driving the engine's bulk-ingestion path.
